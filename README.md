## Propósito
Desarrollar una aplicación web utilizando Python, Flask y Bootstrap que ofrezca un portal informativo corporativo junto con tres herramientas de cálculo operativo (importe de compra con descuento, salario semanal con horas extra y conversión de temperatura) mediante formularios `POST` y renderizado de templates.

## Requisitos para ejecución
* **Python:** Versión 3.10 o superior instalado en el equipo.
* **Git:** Para clonar el repositorio.
* **Navegador web:** Chrome, Edge, Firefox o cualquier navegador moderno.

## Instalación y ejecución local

1. **Clonar el repositorio y entrar a la carpeta del proyecto:**
git clone (URL_DE_TU_REPOSITORIO)
cd portal-servicios

2. **Creación y activación del entorno virtual:**
python -m venv .venv
.venv\Scripts\activate

3. **Instalación de dependencias con `requirements.txt`:**
pip install -r requirements.txt

4. **Comando de arranque:**
python app.py

5. **Dirección local de acceso:**
Abre tu navegador web e ingresa a:
`http://127.0.0.1:5000`
